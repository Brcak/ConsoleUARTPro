# Opt-in updates and selectable components

The application must never download or execute an update without the user's explicit consent. Settings: Off / Notify / Download after confirmation. Default: Notify. Users can choose optional components individually (boardview packs, verified reference databases, firmware packages, device plugins, and integration modules). Each package must have an HTTPS download URL, SHA-256 digest, version, provenance and compatible application version. Download to staging, validate hash, and never overwrite running binaries. Never automatically flash firmware or update board-specific voltage data. Keep diagnostic data evidence classifications: verified, community-reported, experimental. Release publishing and signing are prerequisites for trusted automatic installation. Do not treat a downloaded executable as safe merely because its SHA-256 matches a manifest from an untrusted source.
